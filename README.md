# 🧮 Математика 3 класс — Тренажёр

Интерактивный тренажёр по математике для учеников 3 класса.

## Режимы
- ✖️ Таблица умножения и деления
- ➕ Сложение и вычитание в пределах 1000
- 🧠 Задачи на логику (текстовые задачи)

## Особенности
- Очки и серии правильных ответов
- Сохранение прогресса в localStorage
- Работает офлайн, без сервера
- Адаптивный дизайн (телефон и компьютер)

## Как запустить локально
1. Скачайте все файлы в одну папку.
2. Откройте `index.html` в браузере.

## Как выложить на GitHub Pages
1. Создайте репозиторий `math-3class` на GitHub.
2. Загрузите файлы:
